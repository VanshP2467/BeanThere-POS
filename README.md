# POS–KDS System (WIP)

A work-in-progress **Point of Sale (POS)** and **Kitchen Display System (KDS)** built with **Python** for the backend and **Svelte** for the frontend.
WIP POS-KDS solution written in python and svelte.
This project aims to provide a modern, real-time POS experience with a responsive KDS designed for kitchen workflows.
